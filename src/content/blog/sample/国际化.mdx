## 特性概览

- **智能重定向**：根据 Cookie 或浏览器语言偏好自动跳转至对应语言首页。
- **多语言文章关联**：无需增加子文件夹，通过 `translationKey` 自动关联多语言文章并生成相关 SEO 标签

<FileTree>

- i18n/
  - **index.ts** 国际化核心配置

      - **hero.mdx** 首屏区域（Hero Section）

## 翻译函数

本项目 i18n 翻译通过 [`@aaakul/ts-intl`](https://github.com/aaakul/ts-intl) 实现。

### 基础用法

调用 `getTranslations` 并传入语言代码后，即可通过 `t("namespace.key")` 获取对应翻译：

```astro {10} "t("common.home")"
---
import { getTranslations, type Lang } from "~/i18n";

interface Props {
  lang: Lang;
}

const { lang } = Astro.props;

const t = getTranslations(lang);
---

<nav>
  {/* 直接通过 "命名空间.键名" 读取文本 */}
  <a href={`/${lang}`}>{t("common.home")}</a>
  <a href={`/${lang}/about`}>{t("common.about")}</a>
</nav>
```

### 绑定命名空间（推荐）

如果一个组件内主要使用某个命名空间下的词条，可以在初始化时指定命名空间，调用时直接传入键名：

```astro title="src/components/Header.astro" {7} "tCommon("site_title")"
---
import { getTranslations, type Lang } from "~/i18n";

const { lang } = Astro.props;

// 绑定 `common` 命名空间
const tCommon = getTranslations(lang, "common");
---

<header>
  <h1>{tCommon("site_title")}</h1>
  <button>{tCommon("search")}</button>
</header>
```

### 参数插值

```astro
---
const t = getTranslations(lang, "common");
---

{
  /* const zhHans = {
  common: { link_to: "链接到{title}" } */
}
{/* 自动替换占位符，输出 "链接到 Astro" */}
<p>{t("link_to", { title: "Astro" })}</p>
```

更多用法请参考[说明文档](https://github.com/aaakul/ts-intl#readme)

## 新增语言

为站点添加一门新的语言（例如法语 `fr-FR`），只需以下 4 步：

<Steps>

1. **在站点配置中添加语言代码**

   打开 `site.config.ts`，在 `languageNameMap` 中加入新语言代码与显示名称：

   ```typescript title="site.config.ts" ins={7}
   const SiteConfig = {
     // ...
     languageNameMap: {
       "en-US": "English",
       "ja-JP": "日本語",
       "zh-Hans": "简体中文",
       "fr-FR": "Français",
     },
   };
   ```

2. **创建语言字典文件**

   在 `i18n/messages/` 目录下创建新文件 `fr-FR.ts`。建议复制现有字典文件，并替换其中的翻译文本：

   ```typescript title="i18n/messages/fr-FR.ts"
   const frFR = {
     common: {
       home: "Accueil",
       about: "À propos",
       link_to: "Lien vers {title}",
       page_num: "Page {num}",
       // ... 翻译其余词条
     },
   } as const;

   export default frFR;
   ```

3. **注册新字典**

   打开 `i18n/index.ts`，导入新建的字典并在 `createI18n` 的 `messages` 对象中注册：

   ```typescript title="i18n/index.ts" ins={4,13}
   import zhHans from "./messages/zh-Hans";
   import enUS from "./messages/en-US";
   import jaJP from "./messages/ja-JP";
   import frFR from "./messages/fr-FR";

   export const { getTranslations, getFormatter, isSupportedLanguage, languages, defaultLanguage } =
     createI18n({
       defaultLanguage: "zh-Hans",
       messages: {
         "zh-Hans": zhHans,
         "en-US": enUS,
         "ja-JP": jaJP,
         "fr-FR": frFR,
       },
     });
   ```

4. **添加该语言的作者信息**

   在 `src/content/author/` 下新建对应语言目录（如 `src/content/author/fr-FR/default.mdx`）：

   ```yaml
   ---
   name: "Luka"
   language: "fr-FR"
   occupation: "Développeur Full Stack"
   ---
   ```

</Steps>

## 撰写多语言文章

发布多语言文章时，可以直接在 `src/content/blog/` 中创建 Markdown / MDX 文件。项目根据 Frontmatter 中的 translationKey 自动关联不同语言版本：

<Tabs syncKey="blog-example">
  <TabItem label="中文版本 (介绍.mdx)">

```yaml
---
title: "Astro Plain 介绍"
summary: "博客模板介绍"
translationKey: "my-first-post"
language: "zh-Hans"
date: "2026-09-01T12:00:00Z"
isCanonical: true
---
文章中文内容...
```

  </TabItem>
  <TabItem label="英文版本 (intro.mdx)">

```yaml
---
title: "Introducing Astro Plain"
summary: "Introduction to the blog template"
translationKey: "my-first-post"
language: "en-US"
date: "2026-09-01T12:00:00Z"
isCanonical: false
---
Post content in English...
```

  </TabItem>
</Tabs>

> [!NOTE]
>
> - **`translationKey`**：同一篇文章的不同语言版本必须使用完全一致的 `translationKey`。
> - **`isCanonical`**：建议在默认语言版本设为 `true` ，以生成正确的多语言权威链接（`x-default` 与 `canonical`）。
